JUNTOS CONTRA EL BULLYING
Proyecto educativo — Prevención del acoso escolar
====================================================

CÓMO ABRIR LA PÁGINA
---------------------
1. Descarga el archivo Juntos_Contra_El_Bullying.zip
2. Descomprímelo en cualquier carpeta de tu computadora
3. Abre la carpeta "Juntos_Contra_El_Bullying" y haz doble clic en index.html
4. La página se abrirá en tu navegador (Chrome, Edge, Firefox, etc.)

No necesitas instalar nada ni tener internet, excepto para cargar las
tipografías (Sora e Inter), que se descargan automáticamente desde
Google Fonts. Si no hay conexión, la página funciona igual, solo que
con la tipografía por defecto del navegador.


ESTRUCTURA DEL PROYECTO
------------------------
Juntos_Contra_El_Bullying/
│
├── index.html                 -> Página principal (HTML)
├── README.txt                 -> Este archivo
│
├── css/
│   └── style.css               -> Todos los estilos del sitio
│
├── js/
│   └── script.js                -> Menú, animaciones, contadores,
│                                   actividad interactiva, carrusel
│                                   y botón de compromiso
│
└── assets/
    ├── images/
    │   ├── logo.jpg              -> Logo "Juntos contra el Bullying"
    │   ├── creadores.jpg         -> Fotografía de los creadores
    │   └── ilustraciones/        -> Carpeta libre para ilustraciones
    │                                adicionales (la ilustración del
    │                                encabezado ya está integrada
    │                                directamente en el HTML como SVG,
    │                                por lo que no necesita un archivo
    │                                aparte)
    │
    └── icons/                    -> Carpeta libre para íconos propios
                                     (los íconos del sitio también están
                                     integrados como SVG dentro del HTML)

PERSONALIZAR EL PROYECTO
--------------------------
- Para cambiar textos: edita index.html con cualquier editor de texto.
- Para cambiar colores, tipografía o espaciados: edita css/style.css.
- Para cambiar el comportamiento del menú, la actividad interactiva,
  el carrusel de frases o el botón "Me comprometo": edita js/script.js.
- Para reemplazar el logo o la fotografía: sustituye los archivos
  dentro de assets/images/ manteniendo el mismo nombre (logo.jpg y
  creadores.jpg), o cambia el nombre también en index.html.
- Los nombres de los dos creadores no se incluyeron en el diseño;
  búscalos en index.html (sección "Creadores") y reemplaza el texto
  "Creador del proyecto" por sus nombres reales.
